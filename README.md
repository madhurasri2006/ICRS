# Intelligent Conflict Resolution System (ICRS)

A Flask-based web application that detects conflicts between rules and resolves them using priority, specificity, and reliability.

## Technologies Used
- Python

- SQLite

- CSS
- JavaScript

## Main Features
- Dashboard
- Knowledge Base Management
- Input Facts
- Conflict Detection
- Conflict Resolution
- Decision History

## How to Run Locally

1. Clone the repository.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `python app.py`
4. Open `http://127.0.0.1:5000/` in your browser.
